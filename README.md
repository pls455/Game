# HOTSHOT

لعبة تصويب Multiplayer محلية للأندرويد، تعمل بدون إنترنت عبر نفس شبكة Wi‑Fi / Hotspot.

## الموجود حالياً
- شاشة رئيسية وإنشاء غرفة أو الانضمام بعنوان IP.
- تجربة فردية قابلة للعب.
- Host محلي على المنفذ 5055.
- اتصال اللاعبين داخل الشبكة المحلية فقط.
- إطلاق نار وحركة وأعداء وصحة ونقاط.
- تمرير حزم إطلاق النار بين لاعبي الشبكة المحلية.
- لا Firebase ولا خادم إنترنت ولا حسابات.
- GitHub Actions يبني Debug APK ويرفعه كـ artifact.

## التحكم
- لمس/سحب في النصف الأيسر للتحرك.
- لمس/سحب في النصف الأيمن للتصويب والإطلاق.
- في اللعب الشبكي: أنشئ غرفة على جهاز، ثم أدخل عنوان IP الخاص بالمضيف من الجهاز الآخر.

## الخطة التالية
خرائط ومبانٍ، أسلحة متعددة، لوبي 2–8 لاعبين، مزامنة مواقع اللاعبين، نظام قتل/إعادة ظهور، مؤثرات وصوت، ثم تحسين الأداء والواجهة.

صنع بواسطة كرم - أبو إبراهيم.
